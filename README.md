## 🚀 About

**Berry Brat Generator** is a modern web-based application for generating Brat-style stickers in both **PNG** and **GIF** formats.  
Designed with a premium UI/UX approach and optimized for speed, this tool allows users to create high-quality stickers instantly — without watermark and completely free.

Built as part of the **Berry Mod Apeka ecosystem**.


## 🧩 Features

- 🖼 Static Brat Generator (PNG)
- 🎞 Animated Brat Generator (GIF)
- ⚡ Instant image generation
- 🎨 Premium UI design with glassmorphism
- 📱 Fully responsive for mobile & desktop
- ☁️ Cloud-based rendering
- 🚫 No watermark
- 💯 Free to use
